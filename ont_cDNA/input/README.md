
To run this pipeline, you will need to:

1. locate and ensure the input basecalled sequencing data is in fastq format
2. generate a **sample datasheet file** documenting the samples and barcodes (see examples in the samplesheet folder)
3. generate a **configuration file** of the paths and parameters (see examples in the config folder), applicable to targeted and whole transcriptome datasets for singleplex and multiplexed samples across 1 or more flow cells. 
5. [Optional] generate a **manifest** for running the QC report

Please see [here](https://github.com/SziKayLeung/LRPipeline/wiki/Prepare-your-input-files) for more information to prepare input files.
